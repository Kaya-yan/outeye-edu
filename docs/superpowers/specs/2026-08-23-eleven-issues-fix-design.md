## 第 1 节 · 课件生成管线（问题 6）

### 架构

新建 `backend/app/services/courseware_llm_generator.py`，三个独立生成器取代模板组装：

```
用户点击"生成课件"（选择格式）
   │ 打包上下文：教案（已确认版）+ 白盒分析全量 + 课文全文
   │ + 教学设置（时长/水平/班型）+ 官方组件库定义
   ▼
PPT 链路：LLM 逐页大纲 JSON（标题/要点/讲者备注/视觉提示/交互）→ python-pptx 渲染 16:9
Word 链路：LLM 教学文档结构（封面/目标/逐环节流程/板书/作业）→ python-docx 渲染
HTML 链路：LLM 单文件交互课件（内嵌组件库交互与教学节奏）→ rendered_html 入库
```

### 关键设计点

- **反复制粘贴约束进提示词**：PPT 每页 ≤6 条要点、口语化讲者备注；Word 是教学文档而非教案复读；HTML 按教学环节组织页面并使用组件库交互
- **输出格式契约**：PPT/Word 走严格 JSON Schema（解析失败自动重试一次）；HTML 走结构规范（单文件、无外部依赖、`data-component` 标注与编辑器组件库对齐）
- **长任务**：异步任务 + 前端轮询进度（"正在设计第 3 页…"）
- **降级**：LLM 失败回退现有模板组装，前端标注"简化版生成"，不静默
- **入口**：教案确认后出现三个独立生成入口，各自生成、独立存档
- 保留 `courseware_bootstrap.py` 作降级路径；`editor_schema_json` 结构保留供 V2 编辑器消费；`export_service.py` 的"再导出"与"首次生成"分离

## 第 2 节 · 提示词工程体系（问题 5）

### 九要素骨架（所有生成环节共用）

1. **身份设定**：资深大学英语教学设计师 persona（SLA/CEFR/15 年教龄）
2. **任务目的**：产出什么、给谁用、成功标准
3. **情况描述**：课文全文 + 白盒指标（键名修复）+ 学情画像 + 教学设置
4. **方法库推理（CoT）**：框架库内置，先陈述选择及依据再动笔
5. **约束规范**：时间总和=用户时长；SMART/ABCD 目标；反复制粘贴；每环节有评估点
6. **输出契约**：字段级 JSON Schema / HTML 结构规范
7. **少样本示例**：压缩版黄金范例
8. **自检清单**：返回结构化 `self_check` 字段，前端校验、未过项黄条提示
9. **安全隔离**：`<user_content>` 包裹 + 花括号转义（保留现有）

### 工程化管理

- 提示词模板文件化：`backend/app/prompts/`（`lesson_plan_v2.md`、`courseware_ppt_v1.md`…），版本化、可 diff、可回滚
- 回归测试集：3 篇 demo 课文金标输入，改提示词跑对比防回退
- `self_check` 随产物落库，质量可追溯

### 教案专项修复映射

| 症状 | 修复 |
|---|---|
| 无明确目标 | 新增目标节：3-5 条 SMART 目标（Bloom 层级 + 评估方式） |
| 只有导入活动 | 4-6 环节、时间总和=用户时长、逐环节分钟数 |
| 评价点一句 | 形成性 + 终结性评估点各 ≥2 |
| 指标全 0 | CEFR 键名修复：A1/A2/…/unknown 直传 |
| 内容空泛 | 全文传入（超长课文智能分段摘要） |

同步应用于：plan_reviser、三个课件生成器、文化背景生成。

## 第 3 节 · 白盒分析升级（问题 2b + 3）

### CEFR 三道防线

1. **完整词表**：Oxford 3000/5000（CEFR 逐级标注）+ CEFR-J 融合加载，替换手写词表；预期未分级 70%+ → 10% 以下
2. **专有名词识别**：句中大写开头词、连续大写缩写、地名人名词典 → "专有名词"桶
3. **LLM 兜底分级**：剩余未命中词批量一次调用（JSON 返回），结果写 `word_level_cache` 表持久缓存

前端：未分级柱拆分"专有名词"+"低频词"，图注说明口径。

### 文化背景重构

```
关键词检测（保留，负责召回）
   → LLM 结合课文原句生成词条解释（直接讲清文化点是什么，引用课文原句）
   → 卡片"查看文化知识详情" → RAG/wiki 检索展示来源与延伸背景
```

- LLM 解释走九要素骨架；检索无结果显示"知识库暂无该条目"
- 白盒指标计算保持确定性，仅解释性内容走 LLM

## 第 4 节 · V2-lite 沉浸式编辑器 + V1 过渡（问题 7/8/9）

### V1 关键修复（1-2 天）

| Bug | 修复 |
|---|---|
| 导出被拦截/沙箱警告 | edit/present iframe sandbox 增 `allow-downloads allow-forms allow-modals` |
| 组件点击无反应 | pageManager 委托到 iframeManager 真实 iframe，统一双系统 |
| 动画白屏/PLAN_DATA 冲突 | 弃 doc.write 改 `iframe.srcdoc` + 重设时脚本去重（data-ve-executed 标记） |
| Tiptap 重复 underline | `StarterKit.configure({ underline: false })` |
| Google Fonts 失败 | 编辑器模板改本地系统字体栈 |

### V2-lite 重构（5-7 周）

```
Host（React 外壳）：顶栏 48px + 浮动 Inspector + 浮动组件库
   ↕ postMessage RPC（Origin 隔离）
渲染 iframe（沙箱，无 allow-same-origin）：浏览器原样渲染，动画/JS 正常
```

四大引擎（V2-lite 范围）：
1. **Visual Object Engine**：点击命中视觉对象（几何+计算样式），Host overlay 高亮
2. **Patch Engine**：非破坏性 Patch 集；Undo/快照/导出统一；导出 = 原文件 + `<style id="ve-export-patches">`
3. **Target Resolver**：selector + 结构/内容/几何指纹
4. **Runtime 冻结**：编辑时 `animation-play-state: paused`，预览恢复；不猴补丁 JS API

里程碑：
- M1（第 2 周末）：运行时桥接 + 视觉拾取 + 浮动 Inspector
- M2（第 4 周末）：Patch + Undo + 保真导出
- M3（第 6 周末）：inline 文本 + 图片替换 + Mutation 恢复
- M4（第 7 周末）：30 个平台生成课件 benchmark（视觉编辑成功率分项），达标替换 V1

红线：AI 不直接操作 DOM；不无脑 `!important`；不关浏览器安全边界。
与第 1 节衔接：课件生成 HTML 自带 `data-component`，视觉拾取直接消费。

## 第 5 节 · 前端布局与 UX（问题 1/2a/4/10/11）

### 首页聚焦式（B 方案）

首屏仅：大标题 + 副标题 + 超大输入区（视口 60%，min-h 420px 自增高）+ 居中"开始分析"；标题框内嵌输入区顶端；教学设置移到分析完成后结果页顶部（"生成教案前确认"步骤条）；上传/拍照悬浮左下，词数右下。

### TermTooltip

MetricCard/VerdictCard 整个标签行为触发区；z-index 高于吸顶导航；hover/focus/触屏三场景实测。

### 术语清理

删除"修改后确认/教案是中转点"徽章（换用户视角文案）、edit 页技术徽章、"无法中转"→"内容过大，请精简后重试"；全局扫描用户可见文案的内部术语（中转/白盒/管线/iframe/schema）。

### 公共资料区

"我的资料"页双 Tab：我的资料 | 公共资料。公共资料展示系统知识资产（教学理论库/CEFR 词表说明/文化语料分类），新增只读端点 `GET /knowledge/public`，条目带"官方"徽章与来源；我的资料为零时公共资料自动展开。

### 历史恢复

后端：分析发起时把课文全文与教学设置写入 project 记录。前端恢复协议：有分析结果 → 直接恢复结果视图（白盒 + 教案版本）；无结果 → 恢复输入页完整回填。

## 实施顺序（建议）

1. **第一周**：V1 关键 bug 五连修 + 术语清理 + TermTooltip + 历史恢复断链（全部速效）

4. **第 3-5 周**：白盒升级（词表 → 专有名词 → LLM 兜底缓存 → 文化重构）

6. **穿插**：首页聚焦式改版、公共资料区（独立小任务，任意空档插入）

## 测试与验收

- 每环节金标回归：3 篇 demo 课文跑全链路，人工评估表（目标可测量性/环节完整性/时间总和/反复制粘贴抽查）
