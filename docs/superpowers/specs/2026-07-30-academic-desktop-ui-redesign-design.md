# OutEye Edu 整站 UI 重设计方案（Academic Desktop OS）

- 日期：2026-07-30
- 状态：已完成设计确认，待用户审阅
- 适用阶段：中期 UI 重构
- 关联项目：OutEye Edu 1.0 / 教学课件工作台（HTML 核心）

---

## 1. 背景与目标

OutEye Edu 当前前端已经形成可运行的功能型原型，但旧版界面更接近“工程半成品”而非完整品牌化产品。团队基于四份新的 UI 参考文档，决定发起一轮新的整站 UI 重设计。

本轮设计的关键前提是：

1. **旧版界面不是主约束**，不需要延续旧版深蓝半成品的视觉主导权。
2. **新的设计思路应成为主导**，允许大胆采用莫兰迪色系统、档案抽屉隐喻、桌面叙事与工作台语言。
3. **整体需要融合而不是拼贴**，不能让首页、分析页、项目管理、资源库、知识库、教学课件工作台变成六套割裂风格。
4. **HTML 教学课件工作台已成为产品重点方向之一**，新的 UI 系统需要为其长期扩展预留一致的视觉容器。

因此，本轮重设计的目标不是“美化几页页面”，而是形成一套新的整站设计世界观：

> **Academic Desktop OS（学术桌面操作系统）**

这套世界观需要同时满足：

- 首页有品牌记忆点
- 工作页保持高效率与专业感
- 管理页和内容页形成清晰的档案与文件系统隐喻
- 教学课件工作台与组件库具备可扩展的视觉体系
- 整站风格统一，但不同页面场景表达不同

## 2. 输入来源与设计整合结论

本方案整合自以下四份参考文档：

1. `首页.docx`
2. `登录页 智能分析.docx`
3. `项目管理页.docx`
4. `提示词4--资料库和知识库.docx`

以及以下现有项目事实：

- 当前前端信息架构与功能入口（`UI_REFERENCE.md`）
- 已有页面：首页、登录、注册、智能分析、项目管理、资源库、知识库、专家评审、教材对比
- 已在推进的 **教学课件工作台（HTML 核心）** 模块

整合结论如下：

### 不采用的方式

- 不将四份方案分别生硬落到不同页面
- 不继续以旧版深蓝学术 SaaS 风格作为主基调
- 不让分析页、项目页、资源页、课件页各说各话

### 采用的方式

- 以 **A：Morandi Academic Atelier（莫兰迪学术工作室）** 作为整站主基调
- 以 **B：Desk Archive Narrative（桌面档案叙事）** 作为首页、项目管理、资源/知识库、组件库等场景增强语言
- 以 **C：Soft Intelligence OS（柔和智能操作系统）** 作为分析页、生成页、课件编辑页等高效率工作区语言

最终策略：

> **A 为主，B/C 按场景借用。统一的不是“每页长一样”，而是“每页都说的是同一个世界观”。**

## 3. 核心设计定位

### 3.1 新的整站设计名称

推荐对内对外统一描述为：

- 中文：**学术桌面操作系统**
- 英文：**Academic Desktop OS**

### 3.2 整站叙事

OutEye Edu 不再只是“一个 AI 教学工具网站”，而是：

> **一个让教师在同一张“学术工作桌面”上完成分析、检索、生成、管理、课件制作与课堂展示的智能教研操作系统。**

### 3.3 设计分场景策略

整站分为三个视觉场景层：

#### A. 品牌场景层（Brand Scene）
用于首页、品牌首屏、部分欢迎页。

核心特征：
- 温暖桌面氛围
- 文具与纸张隐喻
- 低饱和莫兰迪底色
- 细腻光影与呼吸感
- 更强的记忆点与传播性

#### B. 档案场景层（Archive Scene）
用于项目管理、资源库、知识库、未来组件库与部分课件管理页。

核心特征：
- 抽屉 / 文件袋 / 档案卡隐喻
- 黑白灰秩序 + 局部莫兰迪辅助色
- 强信息层级
- 低噪音、高识别、可扩展

#### C. 工作台场景层（Workbench Scene）
用于智能分析、教学方案生成、课件编辑器、展示页等。

核心特征：
- 高效率布局
- 更高的信息密度
- 柔和莫兰迪数据卡
- 专业但不过冷
- 强调操作路径与结果反馈

## 4. 全局视觉系统

## 4.1 色彩系统（以莫兰迪为主）

本轮设计不再以旧版深蓝色为主覆盖全站，而是采用暖白 + 莫兰迪低饱和色为系统基底。

### 基础底色

| 名称 | 色值 | 用途 |
|------|------|------|
| Warm Canvas | `#F6F3EE` | 全站主背景 |
| Paper Linen | `#E8E2D8` | 品牌大卡、纸张感模块 |
| Soft White | `#FFFFFF` | 工作台卡片、表单、抽屉卡 |

### 主调莫兰迪色

| 名称 | 色值 | 用途 |
|------|------|------|
| Fog Blue | `#C7D3D4` | 信息、分析、冷静说明 |
| Sage Green | `#CBD6C5` | 成功、生成、主 CTA 候选色 |
| Dust Rose | `#DCCFC8` | 修订、提醒、策略类区域 |
| Clay Beige | `#D8CFC2` | 首页桌面、项目页辅助块 |
| Ink Gray | `#495254` | 深文字、深按钮、主对比色 |

### 规则

1. **整站主背景不再是深蓝，而是 Warm Canvas。**
2. 深蓝只允许作为历史遗留兼容或个别局部信息色，不再主导视觉。  
3. 高饱和强调色只保留极少数局部 CTA / 状态场景，不可泛滥。  
4. 文本主体使用深灰而非纯黑，提高温和度与可读性。  
5. 莫兰迪色在卡片、标签、过滤器、状态块中分层使用，而非整页满铺。

---

## 4.2 字体系统

### 主界面字体

- 英文主字体：**Inter**
- 中文主字体：**Noto Sans SC / PingFang SC / Microsoft YaHei**

用于：
- 项目管理
- 智能分析
- 资源库 / 知识库
- 教学课件工作台
- 表单页

### 品牌装饰字体（仅局部）

- 英文手写：**Caveat / Patrick Hand**
- 中文装饰：少量手写/活泼字体，仅用于首页小标签、场景文案、文具注释

### 原则

- 正文理性统一
- 品牌字体只在首页与少量氛围性场景点缀使用
- 不能把手写风格铺到工作页正文

---

## 4.3 圆角、阴影、留白

### 圆角层级

| 层级 | 建议值 | 场景 |
|------|--------|------|
| 小控件 | 8px | 输入框、细标签、小按钮 |
| 标准卡片 | 12px | 工作台卡片、抽屉卡 |
| 大卡片 | 16px | Hero、统计区、大容器 |
| 品牌块 / 门户块 | 20-24px | 首页桌面块、登录欢迎块 |
| 胶囊 CTA | 999px | 索引标签、主胶囊按钮 |

### 阴影层级

- **品牌场景**：允许更明显阴影，模拟真实物体浮起
- **工作台场景**：柔和阴影，突出效率而非戏剧感
- **抽屉档案场景**：轻量层叠阴影，强调“归档层级感”

### 留白规则

- 模块间距 ≥ 24px
- 卡片内边距 ≥ 20px
- 工作台页保留较大留白，避免信息紧张感

---

## 4.4 统一交互节奏

### Hover
- 上浮 `2-4px`
- 阴影轻微加深
- 不使用夸张抖动作为全站默认反馈

### Selected / Active
- 使用淡色底 + 深色文字
- 必要时加左侧细强调条
- 尽量避免高亮荧光色和强饱和蓝覆盖

### CTA
- 全站主按钮限定 1-2 套主样式
- 优先使用 Ink Gray / Sage Green / Fog Blue 体系
- 保证不同工作区不随意重新定义主按钮语言

### Motion
- 首页可丰富
- 工作页克制
- 抽屉类交互强调平滑展开和弹出反馈

## 5. 页面级风格分工

## 5.1 首页 `/`

### 主风格
- **A 主导 + B 增强**

### 定位
- 整站品牌与世界观入口
- 需要最强记忆点

### 视觉策略
- 采用“桌面文具沉浸式首页”
- 背景为暖白与木纹/纸张隐喻的低饱和版本
- 文具作为功能入口，但用现代 UI 节奏收束
- 可保留猫头鹰助手、桌面物件、学习进度条等强品牌场景元素

### 不建议
- 把首页做成纯深蓝 SaaS Hero
- 把桌面元素铺到所有业务页

---

## 5.2 登录 / 注册页

### 主风格
- **A 主导 + C 收束**

### 定位
- 品牌欢迎门户
- 轻量但有记忆点

### 视觉策略
- 保留分栏欢迎结构
- 一侧为深色 / 深灰蓝大圆角欢迎面板
- 一侧为简洁表单区
- 表单与按钮风格纳入莫兰迪体系
- 登录 / 注册切换使用平滑滑动

### 目标感受
- 比当前普通卡片更有品牌气息
- 比首页克制，避免喧宾夺主

---

## 5.3 智能分析页 `/analysis`

### 主风格
- **C 主导 + A 调色**

### 定位
- 全站最高频的专业工作台之一

### 视觉策略
- 保持四步流程结构不变
- 大幅优化为柔和工作台 UI：
  - 上传区更明确
  - 主按钮始终可见
  - CEFR、可读性、教学洞察卡用莫兰迪数据卡语言重做
  - Step 3 检索结果采用高质量摘要卡
  - Step 4 差异化策略采用双栏或表格

### 规则
- 不引入首页那种强场景文具叙事
- 不回到旧版冷蓝数据控制台风格

---

## 5.4 项目管理页 `/projects`

### 主风格
- **B 主导 + A 配色**

### 定位
- 项目、课件、版本、记录的归档中心

### 视觉策略
- 用“文件抽屉 / 档案卡片”作为主隐喻
- 三段式卡片：
  1. 左侧编号 / 状态条
  2. 中间引导信息
  3. 右侧核心任务 / 项目信息
- 黑白灰秩序 + 莫兰迪辅助色点缀
- 底部可保留一个全局管理 CTA

### 适配未来
- 与教学课件工作台的项目管理体系天然兼容

---

## 5.5 资源库 `/resources`

### 主风格
- **A 主导 + B 结构**

### 定位
- 教学资源的检索与上传中心

### 视觉策略
- 采用“莫兰迪抽屉文件系统”
- 保留顶部搜索 + 上传按钮
- A-Z 索引导航
- 每个抽屉下用文件袋卡表示资源
- Hover 时索引字母弹出、文件袋上浮

### 关键点
- 视觉风格不能只停留在“好看抽屉”
- 仍需保留资源检索效率与摘要可读性

---

## 5.6 知识库 `/knowledge`

### 主风格
- **A 主导 + B 结构**

### 定位
- 语言学理论档案馆

### 视觉策略
- 与资源库保持同一结构
- 但文件袋内容更偏“理论条目 / 学术摘要 / 所属子领域”
- 更强调可信度、结构化与学术秩序

---

## 5.7 教学课件工作台 `/courseware*`

### 主风格
- **C 主导 + B 组件档案借用**

### 定位
- 课程 HTML 课件生成、编辑、展示、组件沉淀的工作台

### 视觉策略
- 主编辑区采用工作台语言：清晰、克制、高效率
- 左侧教学组件库、组件档案、版本区可借用 B 的抽屉/文件袋系统
- 展示端可在局部重新引入首页式品牌氛围，但仍以内容展示优先

### 原则
- 编辑器本体不做文具品牌秀场
- 组件库与课件项目管理适合承接档案隐喻

---

## 6. 资源 / 知识库 / 课件的统一逻辑

这三个模块在新 UI 系统下应形成一条连贯链路：

- **资源库**：管理外部教学资源
- **知识库**：管理语言学理论与内部知识
- **教学课件工作台**：组合资源与知识，形成最终课堂课件

也就是说，这不是三块分散业务，而是一条从内容到教学落地的链路。

因此视觉系统应支持：

1. 资源/理论以档案方式存在  
2. 课件以工作台方式被编辑  
3. 组件以文件袋/抽屉方式沉淀和复用

## 8. 动效系统建议

## 首页 / 品牌页
允许丰富：
- 光斑漂移
- 微弱呼吸感
- 物件弹入
- 文具轻摆
- 助手眨眼

## 工作页
保持克制：
- 卡片 hover 轻上浮
- 淡入 / 滑入
- 面板展开
- loading skeleton

## 抽屉页
强调：
- 高度展开过渡
- 索引弹出
- 文件袋浮起

## 登录页
强调：
- 左右面板滑动
- 输入框聚焦状态
- 按钮按压反馈

## 9. 统一实现原则

1. **不要追求每页一套独立美术风格。**  
2. **必须建立统一 token 系统：色板、圆角、阴影、动效时长、间距。**  
3. **业务页以效率和可读性优先，品牌场景只在必要处增强。**  
4. **教学课件工作台必须与整站统一，而不是另起一套“编辑器风格”。**  
5. **首页是世界观，分析页是效率，项目/资源/知识库是秩序，课件页是生产力。**

---

## 10. 优先级建议

### 第一优先级
1. 智能分析页
2. 登录 / 注册页
3. 项目管理页

### 第二优先级
4. 资源库
5. 知识库

### 第三优先级
6. 首页
7. 教学课件工作台统一风格接入

说明：
- 智能分析页是当前核心使用页，应最先改
- 首页价值大，但工程和视觉要求更高，适合在系统语言稳定后推进
- 课件工作台应在已有功能可用的前提下再接入统一风格系统

## 11. 最终结论

本轮整站 UI 重设计的最终方案是：

> **OutEye Edu 以“莫兰迪学术工作室”为全站主基调，以“桌面档案叙事”和“柔和智能工作台”为场景借用语言，构建一个统一但分场景表达的 Academic Desktop OS。**

它不是旧版深蓝半成品的微调，而是一套新的、完整的、可持续扩展的整站视觉世界观。

这套系统能同时支持：

- 首页的品牌传播
- 智能分析页的专业效率
- 项目管理/资源/知识库的档案秩序
- 教学课件工作台的长期产品延展
